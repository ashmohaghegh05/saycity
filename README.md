# SayCity

Every city. Every voice. Real-time change.

SayCity lets anyone report infrastructure problems, like dark streetlights, potholes and broken sidewalks, by speaking in any language. Each report is translated, located, ranked by risk and sent to the city department that fixes it.

This repository holds the SayCity website: a static site (HTML, CSS and a little JavaScript) with no build step.
